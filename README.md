# Portal de Estudos - Biel

Este repositório contém um único arquivo público: `index.html`.

## Publicação no GitHub Pages
1. Envie `index.html` para a raiz do repositório.
2. Abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione `main` e `/ (root)`.
5. Configure o subdomínio `biel.ulissessales.com.br` no campo **Custom domain**.

O progresso, os flashcards, os tópicos personalizados e o tema ficam salvos no `localStorage` do navegador daquele dispositivo.
